================================================================================
⚡ CONCEPTS CLÉS (Comprendre rapidement)
================================================================================

1. SERVICE LOCATOR (GetIt)
   Avant:   final _authService = AuthService();  // Chaque fois une nouvelle
   Après:   final authService = ServiceLocator.authService;  // Singleton

2. VIEW MODELS (ChangeNotifier)
   Idée: Séparez la logique métier de l'interface
   Profil: ProfileViewModel ← Logique métier
           ProfileScreen ← Affichage/UI

3. CONSTANTES CENTRALISÉES
   Avant:   await service.upload(file, 'avatars')
   Après:   await service.upload(file, AppConstants.supabaseBucketAvatars)

4. VALIDATION CENTRALISÉE
   Avant:   if (email.isEmpty) { /* code */ }  // Répété x4
   Après:   ValidationHelper.validateEmail(email)  // réutilisable

5. ERROR HANDLING UNIFIÉ
   Avant:   catch (e) { showError(e.toString()); }  // Peu informatif
   Après:   ErrorHandler.handleError(e, l10n)  // Message traduit
